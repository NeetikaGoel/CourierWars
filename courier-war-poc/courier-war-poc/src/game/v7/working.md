Tab = switch Courier / Saboteur mode

Courier mode:
Arrow keys = move Courier
Drag = pan map
Wheel = zoom
C = center camera

Saboteur mode:
1 = Red Traffic Light
2 = Road Block
3 = Construction Work
4 = Traffic Jam
5 = Closed Gate
6 = Wrong Direction Sign
7 = Broken Road
8 = Moving Barrier
9 = Security Checkpoint

Move mouse over map = hover validity
Green hover = can place
Red hover = cannot place
Left click without dragging = place selected hurdle



Red Traffic Light works only on traffic signal tiles
Closed Gate works only on tunnel shortcut or bridge entrance
Construction works only on valid district or avenue roads
Saboteur cannot place in Courier current zone
Saboteur cannot place too close to Courier
